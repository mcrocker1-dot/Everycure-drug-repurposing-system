Tiny EveryCure

A miniature version of a real idea used in medicine today: drugs that already work for one disease sometimes work for a second disease too — because they quietly affect the same biology underneath.

What this is

This page walks through a small system built to find "drug repurposing" candidates. It doesn't test anything in a lab or a patient — it just looks at connections that are already known, and asks a simple question over and over: if two different problems share the same underlying switch, could the same drug flip both?

The system knows about six drugs, the diseases they're approved for, and the biological targets — proteins, receptors, pathways — that each drug interacts with. When two things share a target, that's a hint worth writing down.

How it finds a match

Every match follows the same three-step path:

Drug
→
Shared Target
→
New Disease

e.g. Ibuprofen → JAK2 → Psoriasis

Nobody told the system directly that Ibuprofen might help with Psoriasis. It found that path on its own, by noticing that Ibuprofen affects JAK2, and JAK2 is separately known to be linked to Psoriasis. The more targets two things share, the higher the resulting score — a rough measure of how strong the hint is.

Example output

Here's what one result from the system looks like once it's printed:

Drug: Ibuprofen Currently used for: Arthritis May be repurposed for: Psoriasis Shared target: JAK2 Score: 1 Explanation: Ibuprofen may help treat Psoriasis because both are connected to JAK2.

Reading a result

  1. Currently used for shows the drug's actual, established use — the thing it's already known to do.
  2. May be repurposed for is the candidate the system found — never a confirmed treatment, just a lead worth investigating.
  3. Shared target names the biological link that ties the two diseases together through this one drug.
  4. Score counts how many targets are shared. One shared target is a hint. Three or four is a much stronger pattern.

This is a teaching model, not a diagnostic tool. Real systems like EveryCure work from millions of verified biological and clinical data points, reviewed by researchers before anything is tested. This project borrows the same underlying idea — shared targets suggest shared possibilities — at a scale small enough to hold in your head.

Built as a class lab exercise on knowledge graphs and drug repurposing.
